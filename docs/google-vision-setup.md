# 명함 OCR 실행 방식

명함 인식은 현재 브라우저에서 Tesseract.js로 실행합니다. Google Cloud Vision API 키나 결제 설정은 필요하지 않습니다. 명함을 촬영하거나 사진을 고른 뒤 화면에서 명함 영역을 드래그하고 **선택 영역 글자 인식**을 누르세요. 인식된 기관명과 담당자 정보를 확인·수정한 다음 등록합니다.

OCR을 실행하는 동안 사진은 Google Vision으로 전송되지 않습니다. 영업 대상을 등록하거나 기존 영업 대상에 명함을 저장할 때에만 선택한 명함 영역이 비공개 Supabase `sales-cards` 버킷에 저장됩니다. Tesseract 언어 모델 파일을 브라우저가 처음 내려받을 때 네트워크 연결이 필요할 수 있습니다. 이 방식에는 OCR API 호출료가 없지만 앱 호스팅과 저장소의 일반적인 사용량은 별개입니다.

이전에 만든 서버용 Google Vision API 경로는 현재 명함 화면에서 사용하지 않습니다. `GOOGLE_VISION_API_KEY`를 설정해도 사용자 화면이 자동으로 유료 OCR로 전환되지 않습니다.

# 후속 E2E 검증 항목

- 초대 인증 → 가용 일정 선택 → 예약 완료
- 같은 시간 동시 요청 시 중복 예약 거절
- 미인증 사용자의 예약 데이터 접근 거절
- 일반 지원자의 HR API 접근 거절

인증 로직 및 Proxy 쿠키 처리는 `pnpm test`로 자동 검증합니다. 실제 Supabase 프로젝트에서는 아래 통합 검증도 수행합니다.

- 관리자 이메일/비밀번호 로그인 성공 및 잘못된 비밀번호 오류 표시
- 일반 Auth 계정의 로그인 거절 및 `scheduler.interviews` SELECT RLS 차단
- 만료된 세션의 쿠키 갱신 및 비로그인 `/admin` 접근 리다이렉트
- 로그아웃 후 `/admin` 재접근 차단
- 공개 예약 INSERT 후 관리자 목록에 해당 예약 표시
